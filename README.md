# Rework

Projeto Rework organizado em aplicações e recursos independentes.

## Estrutura

```text
Rework/
├── backend/    API Node.js com Express
├── frontend/   Aplicação de interface (a configurar)
├── database/   Scripts e documentação do banco de dados
└── docs/       Documentação geral do projeto
```

## Backend

Com Node.js instalado, execute no PowerShell:

```powershell
cd backend
npm.cmd install
npm.cmd start
```

A API ficará disponível em `http://localhost:3000`.

Consulte também o [README do backend](backend/README.md).
